## 🚀 Featured Projects

### 🧠 [Multi-Tenant AI Customer Support SaaS](https://github.com/kishor007-dev/ai-customer-support-saas)
> *Active · Production-grade SaaS platform*

Businesses deploy their own AI support agents from a centralized dashboard.

- 🔀 Custom **LLM Gateway** routing requests across model providers with token metering
- 🔐 **JWT** (access + refresh tokens) · **Argon2** password hashing · **RBAC** with closed role-permission maps
- 🗄️ **18 MongoDB indexes** across 8 collections — TTL indexes for session cleanup
- 🤖 **RAG pipeline** using `sentence-transformers` (BAAI/bge-small-en-v1.5) for context-aware responses
- 🐳 Fully containerized with **Docker**

`FastAPI` `MongoDB (Motor async)` `React.js` `Groq` `JWT` `Argon2` `Docker` `RAG`
